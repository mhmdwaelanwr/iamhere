# iamhere

A hands-on frontend practice repository focused on building polished product experiences from scratch.

## Current exercise: Apple-inspired product page

This iteration is an **original Apple-inspired visual study**. It borrows the design principles — restraint, whitespace, large typography, premium product framing, and subtle motion — without copying Apple source code, product photography, logos, or marketing copy.

### Skills practiced

- Visual hierarchy and art direction
- Responsive layouts with CSS Grid and fluid typography
- Bento-style feature composition
- CSS-only product/device illustration
- Sticky translucent navigation
- Mobile navigation behavior
- Progressive scroll-reveal interactions
- `prefers-reduced-motion` support
- Semantic HTML and keyboard-friendly navigation
- Progressive enhancement with small vanilla JavaScript

### Stack

- HTML5
- Modern CSS
- Vanilla JavaScript
- No framework
- No build step

### Run locally

Open `index.html` directly in your browser, or serve the directory with any static web server.

For example:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Agent-skill practice

The direction for this exercise was informed by the `awesome-agent-skills` collection, especially the frontend/UI design category. The point is not to ask an agent to generate random code, but to practice a workflow:

1. define the visual direction,
2. implement a focused first pass,
3. review responsiveness and accessibility,
4. test the result,
5. iterate intentionally.
